Ограничения расчёта

    Исторический прогон

    Проверьте прогноз на прошлых периодах: каждый месяц рассчитывается только по предшествующей истории. Сравните результат с продажами и простыми методами.

    Выберите период и запустите проверку.

    Проверка на завершённых месяцах

    Последние шесть завершённых месяцев. Для каждой контрольной даты модель видит только прошлое. Сравниваем прогноз месячных нетто-отгрузок; месяцы с неизвестным фактом исключены. Значения WAPE сравниваются внутри одной единицы измерения.

    По умолчанию используется среднее за три месяца. Сезонная модель выбирается после минимум шести сопоставимых проверок за последние 12 месяцев: ошибка ниже минимум на 20%, победа в двух третях сравнений и без ухудшения на последних трёх. Проверяемый факт в выборе не участвует. Ошибки измерены по полной истории продаж. Сценарий сглаживания разовых всплесков оценивается отдельно. Сравните ошибки методов перед выбором подхода.
    ЕдиницаМетодПрогнозовWAPE ↓MAE ↓Смещение

    WAPE = сумма абсолютных ошибок / сумма факта. MAE — средняя абсолютная ошибка в единицах товара. Положительное смещение означает завышение прогноза. Классический min/max — политика пополнения, а не прогноз, поэтому для неё требуется отдельная симуляция запасов.

    Настройки закупки

    Укажите срок поставки и частоту пересмотра плана. Эти параметры применяются ко всем товарам в расчёте.

    Условия учёта

    Включайте условия после сверки с учётом. Пока они не подтверждены, доступен прогноз без итогового количества заказа.

    Журнал изменений

    Расчёт закупок выполняется локально и привязан к дате выгрузки. При обращении к AI выбранные для ответа данные передаются OpenAI. Проект заказа можно скачать и согласовать с поставщиком.
