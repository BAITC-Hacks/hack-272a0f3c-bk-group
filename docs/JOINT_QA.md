# Совместная проверка рабочего сайта

Дата: 23 сентября 2026. Обе задачи работают с одним исходным кодом.

- Рабочий адрес: `http://127.0.0.1:8765`.
- Изолированная проверка: `http://127.0.0.1:8766`, данные в `data/qa-site/`.
- Проверочные операции имеют префикс `QA-JOINT`; они не добавляются в рабочую базу.
- Задача «Найти похожие проблемы на форумах» проверяет расчёты, импорт, экспорт и сервер.
- Задача «Предложить варианты интеграции LLM» проверяет интерфейс учёта и сквозные операции.

## Проверено через браузер на общем QA-сервере

| Сценарий | Наблюдаемый результат |
| --- | --- |
| Вход через «Работать вручную» | Открываются разделы учёта |
| Создание материала, изделия и склада | Записи сохраняются и доступны в документах |
| Оприходование 10,5 м по 10,25 | Сумма 107,63, документ проведён |

| Продажа 1 изделия по 40,50 | Документ проведён, денежный остаток 40,50 |

| Изменение цены изделия во второй вкладке с 40,50 до 45,50 | Первая вкладка не может сохранить старую карточку; после обновления сохранены исходное название и новая цена 45,50 |

## Ошибки, найденные при совместной проверке

1. После успешной записи и сбоя обновления интерфейс мог показывать старый черновик с сообщением об успехе. Исправлено: результат записи сохраняется, старые действия закрываются, сообщение о неактуальных остатках и деньгах сохраняется до успешного обновления, включая переходы между разделами.
2. Сохранение старой карточки справочника могло затереть новую цену из другой вкладки. Исправлено: сервер проверяет версию записи, показанную при открытии формы. Защита распространяется на товары, контрагентов, склады и задачи.

Исполняемые проверки интерфейса: `node scripts/test_operations_ui.mjs` — 18/18. Они исполняют обработчики поставляемого JS с управляемыми ответами API: сбои после успешной записи, повторные нажатия, целостность снимка данных, версии форм и задач, ручные возвраты и денежное округление.

Финальный серверный прогон второй задачи: 174/174 в `tests`, 6/6 в `analysis`. Отдельно выполнено 600 синтетических сценариев пополнения (36 000 дней движения запасов). Это проверенные сценарии, а не гарантия отсутствия любых ошибок.

## Границы проверенной версии

Это локальный учёт с собственными справочниками и документами. Полное соответствие «МоемуСкладу» не заявляется; подробная карта разделов и дальнейших работ — в `MOYSKLAD_REVIEW.md`.

Возвраты вводятся вручную и требуют сверки с исходной продажей или приёмкой. Фискальные чеки, банк, маркетплейсы, роли пользователей, расчёт себестоимости и автоматическая синхронизация с аккаунтом «МойСклад» не подключены. Реальные запросы к OpenAI/NVIDIA без настроенного ключа не проверялись.
