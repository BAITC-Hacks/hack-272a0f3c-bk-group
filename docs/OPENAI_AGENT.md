# Агент продавца на OpenAI

Откройте сайт, нажмите **Подключить OpenAI**, введите ключ и ID модели, затем сохраните настройки и нажмите **Проверить подключение**. Предложенная модель — `gpt-5.4-mini`; её можно заменить на доступную вашему проекту модель с поддержкой Responses и function calling. После настройки появится AI-помощник. Работа вручную остаётся доступна.

Enter отправляет сообщение, Shift+Enter добавляет новую строку. Для запуска пустого сайта без автоматического чтения архивов Downloads используйте `python app.py --no-auto-load` (или `./start.ps1 --no-auto-load`).

## Возможности

- Находит товары, контрагентов и склады в операционном учёте.
- Читает текущие остатки, документы, сводку локальной кассы и расчёты закупок.
- Объясняет результаты и уточняет недостающие сведения.
- Готовит новые документы всех доступных видов и открытые задачи.

Примеры: «Найди кабель по артикулу … и покажи остаток», «Объясни, почему закупка этого товара заблокирована», «Подготовь заказ покупателя на 10 штук … по цене …», «Создай задачу позвонить клиенту завтра».

Для документа нужны реальные справочники: товар, склад и контрагент, когда он обязателен. Импортная цена 0 может означать незаполненную цену; её нужно уточнить. Агент различает текущий учёт и снимок прогноза с его датой. Он получает ограниченные результаты поиска, а не весь каталог за каждый вопрос.

## Подтверждение действий

Подготовка показывает карточку с реквизитами, строками, количеством, ценой и суммой. Только нажатие кнопки этой карточки сохраняет **черновик документа** или **открытую задачу**. Сам агент не проводит документы, не меняет остатки и деньги, не удаляет записи и не отправляет заказы поставщикам.

Сервер хранит содержание предложения; браузер подтверждает только его ID. Если связанный справочник изменился, сохранение отклоняется и предложение нужно подготовить заново. Повторное подтверждение возвращает ту же запись. Срок предложения — 30 минут. Перезапуск сервера аннулирует диалоги и неподтверждённые предложения. Новый диалог убирает старые карточки из интерфейса.

Сохранённый документ можно открыть и провести обычным способом в рабочем пространстве. Полный функционал «МойСклад», банковские и фискальные интеграции, авторизация нескольких продавцов остаются отдельными этапами проекта.

## Ключ и данные

Ключ вводится в поле пароля на локальном сайте, передаётся локальному серверу и используется только для запросов к `https://api.openai.com/v1/responses`. Сервер не возвращает его в API-ответах; UI очищает поле после сохранения или закрытия настроек и не использует localStorage для ключа.

Варианты хранения:

- До остановки сервера — только в памяти процесса.
- С сохранением — зашифрованный Windows DPAPI файл `data/openai-settings.json`, привязанный к текущей учётной записи Windows. В файл и временный файл попадает только шифротекст; `data` исключён из Git.
- Переменные окружения `OPENAI_API_KEY` и `OPENAI_MODEL` перед запуском.

Приоритет: настройки сеанса → сохранённые настройки → окружение. Временная настройка не удаляет ранее сохранённый ключ. DPAPI не заменяет защиту учётной записи Windows. Текущая версия сайта предназначена для одного локального пользователя.

Сохранение настроек не вызывает модель. **Проверить подключение** отправляет короткое «Reply with OK.» без данных компании. При отправке поручения в OpenAI передаются текст диалога и результаты запрошенных инструментов. История ограничена шестью последними парами сообщений. Параметр `store: false` не равнозначен гарантии нулевого хранения данных у провайдера. Использование API оплачивается по условиям OpenAI.

## Реализация и проверка

`procurement/agent.py` ведёт диалоги на сервере и ограничивает один ответ шестью раундами, 12 вызовами инструментов и 120 секундами. `agent_tools.py` реализует 10 строгих схем инструментов и отдельное подтверждение. `agent_settings.py` хранит настройки. `web/assistant.js` показывает чат, настройки и карточки.

Тесты используют временные базы и подставной транспорт; реальные ключи и данные компании наружу не отправляются:

```powershell
python -m unittest discover -s tests -p "test_agent*.py" -v
node scripts/test_agent_ui.mjs
```

Сквозной браузерный стенд: `python scripts/qa_agent_server.py --port 8766`. Он использует отдельный временный каталог и фиксированные ответы, никогда не подключается к OpenAI. Производственный `app.py` не имеет переключателя на эти ответы.

Официальные источники: [Responses function calling](https://developers.openai.com/api/docs/guides/function-calling), [gpt-5.4-mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini).
