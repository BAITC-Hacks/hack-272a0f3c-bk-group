## Сквозная проверка в браузере

Отдельный стенд `scripts/qa_agent_server.py`, порт 8766, временная база в `outputs`, один фиктивный товар QA-CABLE и тестовый склад. Проверено:

1. Без ключа открывается обычное рабочее пространство; кнопка подключения доступна, чат скрыт.
2. Настройки принимают фиктивный ключ только на тестовом стенде; поле очищается после сохранения. Подключение не выдаётся за уже проверенное.
3. Кнопка проверки вызывает отдельный тестовый запрос без бизнес-данных.
4. В чате выполняются поиск товара, поиск склада и подготовка оприходования 10 м × 12.50 = 125.00.
5. Карточка показывает товар, склад, дату, количество, цену и сумму. После нажатия «Сохранить черновик» обе кнопки подтверждения/отклонения выключаются.
6. «Открыть документы» приводит в реестр: ровно один документ со статусом «Черновик» и суммой 125.00.
7. В консоли браузера нет ошибок; итоговый вид чата проверен визуально.
